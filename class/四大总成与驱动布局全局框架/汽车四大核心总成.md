# 第1课：整车四大总成+驱动布局全局框架
## 一、本课学习目标
1. 记住汽车四大核心总成，理清相互协作逻辑；
2. 看懂5种主流整车驱动布局结构与适用车型；
3. 完整列出全书会重点拆解的冷门精密零件清单；
4. 分清原厂件、品牌配套件、副厂件、改装件基础定义，铺垫后续品牌优劣对比课程。

## 二、汽车四大核心总成（所有车辆通用，燃油/电车通用框架）
### 1. 动力总成——车辆动力来源
负责把**化学能（汽油/柴油）或电能转化为旋转扭矩**，给整车提供驱动力。
- 燃油车核心：`发动机、涡轮、中冷器、燃油供给、排气系统、点火系统`
- 混动/增程新增：`发电机、行星齿轮耦合机构`
- 纯电车替换：`驱动电机、动力电池、电机减速器齿轮、高压电控`
- **本课重点标记冷门件**：`涡轮浮动轴承、VVT调节齿轮、水冷中冷、机油泵齿轮、行星排齿轮`

### 2. 底盘总成——动力传递+行驶操控承载
承接**动力总成输出的扭矩**，控制车辆走、停、转向、滤震，是机械齿轮、阀件最**密集**的总成。
包含四大子系统：
- 传动系统：`离合器、变速箱全套齿轮、同步器齿环、差速器锥齿轮、半轴`
- 行驶系统：`车轮、轮毂、悬挂摆臂、各类衬套、减震器`
- 转向系统：`转向机齿条齿轮、转向拉杆`
- 制动系统：`刹车总泵、分泵、真空助力阀、ABS阀体`
标记冷门件：`差速器齿轮、同步器齿套、转向机齿轮、泄压单向阀`

### 3. 车身总成——承载、防护、座舱空间
分为**承载式/非承载式**两类，作用容纳乘客、吸收碰撞冲击力、安装全部外部附件。
- 外部：`保险杠、防撞梁、翼子板、车门、ABC柱、扰流板`
- 内部：`仪表台骨架、座椅调节齿条、门锁齿轮、顶棚隔音结构`
>冷门小件：`车门锁止齿轮、底盘导流扰流片、车身加强筋连接板`

### 4. 电气电子总成——全车控制、供电、感知
分为**低压12V系统、新能源高压系统两大体系**，相当于车辆的**神经与大脑**。
- 低压：`电瓶、车灯、传感器、车窗升降电机、空调控制面板`
- 高压（混动/纯电）：`VCU整车控制器、MCU电机控制器、BMS电池管理、高压配电盒`
>精密冷门件：`各类压力传感器、真空电磁阀、压差传感器、高压绝缘保险丝`

## 三、四大总成完整工作逻辑（一句话闭环）
>动力总成输出扭矩 → 底盘传动齿轮机构传递动力驱动车轮行驶 → 车身承载人与设备并提供防护 → 电气总成实时采集全车数据、自动调节动力/冷却/制动，全程协同运转。

## 四、五大整车驱动布局（结构、优缺点、适用车型）
### 1. FF前置前驱（家用轿车/SUV主流）
**发动机、变速箱全部布置在前机舱，只驱动前轮。**
- 优点：`结构紧凑、车内空间大、传动距离短、成本低；`
- 缺点：`急加速重心后移，前轮抓地力下降，大马力易打滑，操控上限低。`
>内部齿轮特点：横置变速箱，体积小，无长传动轴。

### 2. FR前置后驱（豪华轿车、后驱跑车、硬派轿车）
**发动机前置，通过传动轴把动力输送至车尾差速器，驱动后轮。**
- 优点：`前后轴配重均衡，转弯操控好，大马力起步不抢转向；`
- 缺点：`传动轴占用车内地板空间，成本更高。`
>核心冷门结构：`长传动轴、后桥差速器齿轮组。`

### 3. RR后置后驱（超跑、老款保时捷911）
**发动机布置车尾，直接驱动后轮。**
- 优点：`后轮载荷大，起步抓地力极强`
- 缺点：`车头轻，低速转向容易推头，维修空间狭小。`

### 4. 4WD/AWD四驱（越野、高性能SUV、性能车）
**同时驱动四个车轮，分分时四驱、全时四驱、适时四驱。**
- 优点：`烂路、雨雪路面抓地力最强`
- 缺点：`齿轮机构多，重量大，油耗更高。`
>独有冷门零件：`分动箱齿轮、中央差速器多片离合器、扭矩分配行星齿轮。`

### 5. 增程专用串联布局（理想、问界等增程式车型）
**发动机仅连接发电机发电，不直接驱动车轮，车轮完全由电机带动。**
>独有部件：`发电电机、电机减速齿轮、大容量动力电池。`

## 五、全书重点冷门零件总清单（后续课程逐一深度拆解）
1. 涡轮系统：浮动轴承、废气旁通泄压阀、空气/水空中冷器、涡轮密封油环

5. 车身小件：门锁传动齿轮、底盘扰流导流板、车门密封单向阀

## 六、配件等级基础区分（为后期品牌优缺点课程铺垫）
1. 原厂件：车企配套原厂代工，装车原配，匹配度最高，价格最贵；缺点：改装潜力极低，散热/强度设计偏向家用耐用，性能上限低。
2. 一线品牌配套件（马勒、舍弗勒、博格华纳、盖瑞特）：主机厂同款代工厂出品，质量接近原厂，性价比高；不同品牌各有侧重，后续专项课对比优劣。
3. 普通副厂件：国产小厂仿制，价格极低；缺点：齿轮精度差、中冷散热翅片薄、密封差，易漏油、增压漏气、磨损快。
4. 竞技改装件（加大中冷、强化涡轮、锻造齿轮）：强化材质，散热/强度拉满；缺点：低速阻力大、成本极高，部分会损失日常燃油经济性。
