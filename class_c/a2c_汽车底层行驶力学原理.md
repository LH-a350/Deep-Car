# 第2课：汽车底层行驶力学原理
## 本课学习目标
- *搞懂车辆前进、减速、转向涉及全部作用力；*
- *分清静摩擦/滑动摩擦，理解轮胎打滑本质；*
- *建立扭矩、马力、转速基础概念（不堆砌复杂公式）；*
- *掌握重心转移、转弯侧倾、推头/甩尾底层成因；*
- *关联后续：悬挂、轮胎、差速器、变速箱的设计逻辑。*

## 一、车辆行驶五大阻力
***车辆想要向前移动，动力总成输出的驱动力，必须克服所有阻力总和：***
- **滚动阻力**:`轮胎受压持续形变、橡胶与地面微观摩擦产生。胎压越低、轮胎越软、载重越大，滚动阻力越高。
低速工况下，滚动阻力是最主要阻力；高速占比下降`
> 延伸：扁平比大的舒适胎，滚动阻力高于低扁平比运动胎。

- **空气阻力**:`气流撞击车头、车身周边气流分离、车尾负压拖拽形成。空气阻力和车速平方成正比。车速翻倍，空气阻力变为4倍。这也是为什么高速再加速非常耗油/耗电，也是跑车大量空气套件存在的意义。`

- **坡道阻力**:`上坡需要对抗重力分力；下坡坡道阻力反向，会推动车辆滑行。`
- **加速惯性阻力**:`物体保持原有运动状态。起步、急加速时，动力需要额外克服整车惯性；松开油门滑行，惯性会让车辆继续前进。`
- **机械阻力**:`发动机内部摩擦、变速箱齿轮啮合摩擦、轴承阻力、半轴阻力。机油状态、齿轮油粘度、轴承磨损都会直接改变机械阻力大小。`

> 总结动力平衡公式（通俗版）:
>- **驱动力 ≥ 滚动阻力+空气阻力+坡道阻力+加速阻力 → 车辆加速/匀速**
>- **驱动力 ＜ 总阻力 → 车辆减速**

## 二、驱动力来自轮胎摩擦 *（核心重点）*
***旋转的轮胎胎面试图相对于地面向后滑动，地面给轮胎一个向前的静摩擦力，这个摩擦力才是推动整车前进的真正驱动力。***

### 静摩擦 vs 滑动摩擦
1. **静摩擦（正常行驶）**
`胎面和地面没有相对滑动，抓地力最强。`
2. **滑动摩擦（打滑）**
`发动机扭矩过大，轮胎转速过快，胎面持续空转。滑动摩擦力远小于最大静摩擦力。
现象：起步烧胎、雨雪路面失控、大马力前驱车急加速前轮空转。`

>关键结论：
无论发动机有多大马力，**最大驱动力上限 = 轮胎最大静摩擦力**。
这就是大马力车需要加宽轮胎、提升抓地力的根本原因。

## 三、扭矩、马力、转速通俗解析（重中之重）
### 1. 扭矩 *（N·m）*
**简单理解：旋转的“劲”**

代表曲轴/驱动轴瞬间输出的扭转力量。

低转速就能输出大扭矩：`起步、爬坡、重载更轻松（涡轮车、电机典型特征）。`

### 2. 马力 *（功率）*
***代表做功快慢，衡量持续加速能力。***
>公式逻辑：`马力由扭矩和转速共同决定。
相同扭矩下，转速越高，马力越大。`

>形象举例：
>- 扭矩 = 一次能推动多重的重物
>- 马力 = 能多快连续推动重物

- 电机：`0转速输出最大扭矩，低速爆发力强；`
- 自然吸气发动机：`扭矩随转速缓慢爬升；`
- 涡轮增压发动机：`到达起压转速后扭矩快速爆发。`

### 3. 延伸知识点（为变速箱课程铺垫）
*发动机原生扭矩有限，变速箱内部大小齿轮组，作用就是 **放大扭矩**，低速挡位放大倍率更高。*

## 四、制动受力与重心转移
>车辆刹车时，惯性使整车重心向前移动：
>- 前轮垂直载荷上升 → 前轮抓地力变大；
>- 后轮载荷下降 → 后轮抓地力降低。
现象：刹车车头下沉。

***反之：急加速，重心向后转移，车尾下沉。***
- 前置前驱FF急加速：`前轮载荷降低，容易打滑，转向力同时变弱；`
- 前置后驱FR急加速：`后轮载荷增大，起步抓地力提升，这是后驱适合大马力的核心力学原因。`

## 五、转向、离心力与车身侧倾
***车辆转弯时产生离心力，惯性试图让车辆维持直线行驶。
离心力大小和车速正相关，转弯半径越小，离心力越强。***

1. **车身侧倾原理**
`离心力作用在车辆重心，重心高于悬挂支点，会形成力矩，挤压外侧悬挂压缩，内侧悬挂拉伸，车身向弯道外侧倾斜。
侧倾不是缺陷，悬挂衬套、减震、弹簧设计需要平衡侧倾幅度；过度侧倾会改变轮胎接地角度，削弱抓地力。`

>两种基础转向特性
>- **推头（不足转向）**：前轮先突破抓地极限，车辆有向外冲出弯道趋势，多数家用前驱轿车原厂调校倾向轻微推头，安全性更高；
>- **甩尾（过度转向）**：后轮先失去抓地力，车尾向外滑动，常见后驱激烈驾驶，操控上限高，操控难度更大。
